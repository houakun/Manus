# Step 9b：读路径"不可自证"故障 2×2（`silent_wrong_result`）—— 第三个负结果，以及三次实验合起来的结论

> 对应计划 T7（T6 为负结果时的备选）。
> `docs/step9-readpath-2x2.md` 证明了"**可见**的读路径损坏会被重读覆盖"；
> 本节测的是剩下那一类：**结构正常、内容错**（`silent_wrong_result`）——
> 它本该是"重读也发现不了"的故障。

---

## 一、$0 前提检查（先读轨迹，再决定跑什么）

T6 的机制结论是：注入次数与 `read_file` 次数**一一对应**（inj=1→2、2→3、3→4）——
即 Agent 会**重读**它刚读到的东西。于是候选只剩一类：
**损坏在内容上不可见**（结构合法、字段齐全，但值是错的）—— 重读拿到的还是**同一个错值**，
理论上无法自证。

选定的故障：`silent_wrong_result@read_file(rate=0.5)`（只在只读工具上生效，见 `lab/faults/injector.py`）。

**为什么不是"再加一个 guard 能力"**：那是另一件事（T7 的选项 b），
而本次要先把"故障是否可自证"这个前提**单独测干净** —— 否则加了能力也说不清收益来自哪。

## 四、机制：为什么"静默错"也没静默 —— **重读会暴露不一致**

把"注入次数"与"事件流里 `read_file` 次数"对上（$0）：

| 注入次数 | 该次运行的 `read_file` 次数 |
|---|---|
| 1 | 2 |
| 2 | 3 |
| 3 | 4 |
| 5 | **9** |

**规律与 T6 完全一致**：每被破坏一次，就多读一次。关键在 `rate=0.5` 的语义：

> 损坏是**每次读取独立**的 —— 重读**有可能拿到干净内容**。
> 于是 Agent 在两次读取之间看到**同一个文件给出两个不同的值** → 它发现"不一致"，
> 继续读/交叉验证，最后交付正确的产物。

加固臂还触发了 **6 条内容级后置校验告警**（全部在 `sem_config_merge`，每次运行 2 条），
说明检测层确实工作了；而**没有失败可修**，所以"检测→恢复"这一步依然没有收益空间。

| "加固的成本/工具增量（+3.9% / +5.2%）**落在地板之内**且方向不可信（区间跨 0）" | "加固更贵" —— 区间跨 0 |
| "机制是**重读暴露了不一致**：注入 1/2/3/5 次分别对应 2/3/4/9 次 `read_file`" | "这个 Agent 免疫所有静默故障" —— 只覆盖了**每次读取独立损坏**这一类 |

| "**三次实验（写路径 / 读路径可见损坏 / 读路径内容错）合起来**：凡是在重复查看之间**不稳定**的损坏，都会被这个 Agent 的自检循环覆盖" | "所以不需要加固" —— 反例还没构造出来（见 §6） |

## 六、三次实验合起来的结论，以及**下一个可证伪的方向**

| 实验 | 故障 | 对 Agent 是否可自证 | 结果 |
|---|---|---|---|
| `docs/ab-guard-experiment.md` | `partial_write`（写路径截断） | 可（写完会读回） | 负结果（两臂都 100%） |
| `docs/step9-readpath-2x2.md` | `truncated_result`（读回内容被截短） | 可（内容明显不完整） | 负结果（两臂 21/21） |
| 本节 | `silent_wrong_result`（内容错、结构正常） | **本以为不可**，实测**可以**（重读暴露不一致） | 负结果（两臂 21/21） |

**统一起来的机制**：这个 Agent 会**反复查看同一处**，所以只有"**在重复查看之间保持一致**"的损坏
才可能骗过它。前三次故障都不满足这一点（写路径可回读、截断可见、内容错在重读时自相矛盾）。

**下一个（也是唯一剩下的）方向**：让损坏**跨读取保持稳定** —— 例如
- 故障注入改成"**同一文件的同一次损坏在整个运行内固定**"（键 = 文件路径而非调用序号），
  这样重读拿到的是**同一个错值**，不一致消失；
- 或者用一个**不可复核的外部事实**（例如目标里引用的一个外部编号）被稳定地改错。

> 这一条现在是**可证伪的**：如果做了"稳定损坏"仍然是 100%，那说明这个 Agent 的自检能力
> 比我们以为的更强（那就该换问法：它靠什么发现的？）；如果它失败了，那才第一次证明
> "guard 的检测层有净收益空间"。
>
> **纪律**：在拿到那个结果之前，本节与 T6 的负结果**都是可交付的结论**
> （"对自验证型 Agent，只要损坏在重复查看间不稳定，加固的恢复能力就没有用武之地"），
> 但**不能**推广成"加固没用"。
